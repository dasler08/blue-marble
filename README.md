# Blue Marble

<img width="1163" height="906" alt="image" src="https://github.com/user-attachments/assets/1179e72c-975d-4d4d-b411-6fd52d4e0aca" />

A geopolitical simulator on the real Earth. Pick any country as it stood in 2026 and run it: the budget, taxes, laws, ministers, diplomacy and wars. Every country starts from real data and keeps going without you.

## Download

**[Get the latest release](../../releases/latest)**

Extract the zip and run `Blue Marble.exe`. Windows 10 or 11, 64-bit.
